# CatLu IPTV

<p align="center">
  <img src="IptvPlayer/Assets/catlu.png" alt="Кот CatLu IPTV" width="240" />
</p>

IPTV-плеер для **Windows 10/11 x64**: прямой эфир, программа передач, архив и запись видео в одном приложении.

**[Скачать последнюю версию](https://github.com/Maksimasz/CatLuIPTV/releases/latest)** · [Все релизы](https://github.com/Maksimasz/CatLuIPTV/releases) · [Сообщить о проблеме](https://github.com/Maksimasz/CatLuIPTV/issues)

> Приложение не содержит телеканалов и подписок. Для просмотра нужен ваш плейлист и доступ к IPTV-провайдеру.

## Возможности

- **Плейлисты:** несколько списков M3U/M3U8, загрузка из файла или по HTTP/HTTPS, переключение между ними.
- **Каналы:** группы, поиск, избранное и автоматический запуск последнего просмотренного канала.
- **Программа передач:** XMLTV в форматах XML и GZ, несколько источников EPG, резервные копии и время в часовом поясе компьютера.
- **Архив:** выбор дня и прошедшей передачи, перемотка на 30 секунд назад и вперёд, возврат в прямой эфир.
- **Запись:** сохранение текущего прямого эфира в TS без перекодирования, с отображением длительности и размера.
- **Полный экран:** управление поверх видео и автоматическое скрытие панели.
- **Обновления:** проверка при запуске, каждые 24 часа и вручную; установка поверх прежней версии с сохранением данных.

## Установка

1. Откройте [последний релиз](https://github.com/Maksimasz/CatLuIPTV/releases/latest).
2. Скачайте файл установщика `CatLu-IPTV-…-Setup-x64.exe`.
3. Запустите установщик, затем откройте **CatLu IPTV** из меню «Пуск».

.NET 8 и LibVLC уже включены. Отдельно устанавливать VLC, Python или uv не нужно. Установка выполняется для текущего пользователя без прав администратора.

При обновлении удалять предыдущую версию не требуется: плейлисты, избранное, настройки и EPG сохраняются. Контрольная сумма установщика находится в `SHA256SUMS.txt` рядом с файлом релиза.

Установщик пока не подписан цифровым сертификатом, поэтому Windows может показать предупреждение SmartScreen.

## Первый запуск

1. В меню **⚙ → Плейлисты** добавьте список: укажите название и путь к M3U/M3U8 либо ссылку HTTP/HTTPS.
2. Нажмите **⚙ → Обновить EPG**, чтобы загрузить программу передач. Также можно подключить свой XMLTV из файла или по ссылке.
3. Откройте **«Каналы»** и запустите канал двойным щелчком или кнопкой воспроизведения.

Звёздочка рядом с каналом добавляет его в избранное. Поиск работает по названию канала и группе.

## Архив передач

Если провайдер предоставляет архив, выберите канал и нажмите **«Архив»** в панели программы передач. Выберите день и передачу, затем нажмите **«Смотреть передачу»** или сделайте двойной щелчок.

- **«−30 с» / «+30 с»** — перемотка, в том числе в полном экране.
- **«В эфир»** — возврат к текущей трансляции.

Поддерживаются совместимые плейлисты с `tvg-rec` и адресацией архива через `utc/lutc`. Глубину архива определяет провайдер. Для выбора передачи требуется EPG за нужный день: само расписание не содержит видео.

## Запись эфира

Во время просмотра прямого эфира нажмите **«● Запись»** и выберите новое имя файла `.ts`. Для завершения нажмите **«■ Стоп запись»**.

Видео сохраняется без перекодирования. Можно смотреть другой канал или поставить просмотр на паузу — запись исходного канала продолжится. При обычном закрытии приложения запись завершается и сохраняется.

Компьютер и плеер должны оставаться включёнными. Запись использует отдельное подключение к провайдеру; учитывайте ограничения вашей подписки. После аварийного завершения полученная часть остаётся в выбранной папке как `*.part.ts`.

## Программа передач

Плеер использует основной источник [EPG.ONE](http://epg.one/epg2.xml.gz) и дополнительные источники: [IPTV-EPG](https://iptv-epg.org/), [BCU Media](https://bcumedia.pro/epg.xml.gz), [IPTVX.one](https://iptvx.one/EPG) и [TVTeam](http://epg.team/tvteam.xml.7.2).

Дополнительные источники заполняют пробелы в расписании. Для поддерживаемых израильских каналов доступны русские расписания, если они есть в источниках.

При запуске источники обновляются, если сохранённые данные старше 12 часов или не читаются. Сначала загружается локальное расписание. При ошибке обновления предыдущая копия сохраняется.

Хранятся до **7 прошедших дней и 3 будущих дней по UTC**, если источник их предоставляет. Покрытие каналов и полнота расписания зависят от источников. Периодическое обновление EPG при постоянно открытом плеере пока не реализовано.

## Управление

| Действие | Управление |
|---|---|
| Начать просмотр | Двойной щелчок по каналу или кнопка воспроизведения |
| Показать или скрыть список каналов | «Каналы» |
| Показать или скрыть программу передач | «Программы» |
| Полный экран | F11 или кнопка полного экрана |
| Выйти из полного экрана | Esc или F11 |
| Показать панель в полном экране | Движение мыши |

## Данные и приватность

В установленной версии настройки, ссылки на плейлисты и кеш EPG хранятся в:

```text
%LOCALAPPDATA%\CatLu IPTV
```

Персональные ссылки на плейлисты могут содержать ключи доступа. Не публикуйте файл `player-settings.json` и содержимое папки данных. Личные плейлисты, ключи и готовые файлы EPG не входят в установщик.

Записи сохраняются в выбранную вами папку. Исходный локальный плейлист плеер не перезаписывает. Удаление приложения не удаляет папку пользовательских данных.

## Сборка из исходников

Технологии: **C# · .NET 8 · WPF · LibVLCSharp**.

Для разработки нужны Windows x64 и .NET 8 SDK. Выполняйте команды из корня репозитория:

```powershell
git clone https://github.com/Maksimasz/CatLuIPTV.git
cd CatLuIPTV
dotnet run --project .\IptvPlayer\IptvPlayer.csproj
```

Для сборки установщика дополнительно нужен Inno Setup 6 или 7:

```powershell
.\installer\build.ps1
```

Установщик и `SHA256SUMS.txt` появятся в `release\<версия>\`. Версия берётся из `IptvPlayer.csproj`.

Проверки:

```powershell
dotnet run --project .\test\Checks\Checks.csproj
dotnet run --project .\test\WindowChecks\WindowChecks.csproj
```

Python и uv нужны только для отдельного инструмента ручной подготовки EPG — `build_epg.py`.

## Ограничения

- Запись по расписанию и запись архива пока не поддерживаются.
- Нет ручного сопоставления каналов с EPG.
- Другие форматы catch-up, специальные HTTP-заголовки и `#EXTVLCOPT` не поддерживаются.
- Избранное различает каналы по названию и группе: совпадающие названия и группы имеют общую отметку.
- Воспроизведение и архив зависят от доступности потоков и условий провайдера.

Нашли ошибку? [Создайте issue](https://github.com/Maksimasz/CatLuIPTV/issues) с версией приложения и шагами воспроизведения. Не прикладывайте ключи доступа и персональные ссылки на каналы.
