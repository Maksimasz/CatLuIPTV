# CatLu IPTV

Плеер для Windows x64: C# / .NET 8, WPF, LibVLCSharp.

Возможности: локальные M3U/M3U8, группы `group-title` и `#EXTGRP`, поиск, избранное, XMLTV/сжатый EPG, текущая и следующая передачи, полноэкранный режим. Выбранные файлы, канал и фильтры сохраняются локально. Кнопка «Обновить EPG» скачивает полный архив EPG.ONE и готовит облегчённую программу за три дня назад и три дня вперёд. Предыдущая рабочая версия сохраняется. Обновление запускается вручную кнопкой.

## Состав

- `IptvPlayer/` — исходники приложения и подробная инструкция.
- `test/` — проверки C# и анализаторы EPG на Python.
- `build_epg.py` — отдельная подготовка облегчённого EPG через Python.

## Восстановление и запуск

Текущие пути приложения настроены на `D:\web\epg`. Для восстановления клонируйте репозиторий в эту папку. Потребуется .NET 8 SDK с поддержкой Windows Desktop.

Создайте `resurses`, поместите свой локальный плейлист в `resurses\playlist.m3u8`. Исходный полный EPG доступен по адресу http://epg.one/epg2.xml.gz. Облегчённый EPG можно получить кнопкой «Обновить EPG» в плеере; предварительное ручное скачивание не требуется.

```powershell
dotnet run --project .\IptvPlayer\IptvPlayer.csproj
```

Сборка готового приложения:

```powershell
dotnet publish .\IptvPlayer\IptvPlayer.csproj -c Release -o .\IPTV
```

Запуск сборки: `IPTV\CatLu IPTV.exe`. Сохраняйте вместе всю папку `IPTV`, включая библиотеки.

## Проверки

```powershell
dotnet run --project .\test\Checks\Checks.csproj
```

Проверяются чтение M3U/XMLTV, часовые пояса, фильтры групп, несколько избранных каналов, совместимость настроек, безопасное обновление EPG и резервная копия. Обычный запуск проверок не обращается к сети.

## Отдельная подготовка EPG

Для существующего Python-сборщика требуется Python 3.14 и uv. Распакуйте полный архив в `resurses\epg2.xml`, затем выполните:

```powershell
uv run python build_epg.py
```

Результат — `resurses\epg_small.xml.gz`. При использовании кнопки обновления Python не требуется.

## Локальные данные

Плейлисты, адреса потоков, EPG, личные настройки, виртуальное окружение и готовые сборки исключены из Git. Репозиторий сохраняет код проекта; личный плейлист необходимо хранить отдельно. Не добавляйте персональную ссылку M3U в код или сообщения об ошибках.

## Видео и полный экран

Кнопка «Программа» сворачивает и раскрывает программу передач справа. Кнопка расширения под видео или F11 включает режим, в котором всю область экрана занимает видео. Панели, заголовок окна и отступы скрываются. Движение мыши показывает снизу панель с названием канала, текущей и следующей передачами, прогрессом, воспроизведением, паузой, остановкой, громкостью и кнопкой «Выйти». Панель скрывается через три секунды без действий; при работе с её элементами остаётся видимой. Esc, F11 или «Выйти» возвращают прежнее расположение панелей и размер окна. Переход между режимами использует тот же экземпляр проигрывателя.

Проверка компоновки и переключения режимов (Windows):

```powershell
dotnet run --project .\test\WindowChecks\WindowChecks.csproj
```

Эта проверка не запускает сетевые потоки и не изменяет личные настройки.
