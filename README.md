# CatLu IPTV

IPTV-плеер для Windows 10/11 x64. **Текущая версия — 0.0.6.** Отправная точка проекта сохранена в [релизе 0.0.5](https://github.com/Maksimasz/windows-iptv-player/releases/tag/v0.0.5).

## Установка 0.0.6

1. Откройте [релиз v0.0.6](https://github.com/Maksimasz/windows-iptv-player/releases/tag/v0.0.6).
2. Скачайте `CatLu-IPTV-0.0.6-Setup-x64.exe` и запустите установщик.
3. Запустите CatLu IPTV из меню «Пуск» или ярлыка на рабочем столе, если выбрали его создание.

Установка выполняется для текущего пользователя без запроса прав администратора. Папка по умолчанию: `%LOCALAPPDATA%\Programs\CatLu IPTV`. Среда .NET 8 и LibVLC уже включены: отдельно устанавливать .NET, VLC, Python или uv для работы плеера не нужно. Установщик пока не имеет цифровой подписи. Рядом с ним опубликован `SHA256SUMS.txt` для проверки целостности.

## Первый запуск

1. Откройте меню **⚙** и нажмите **«Открыть M3U»** и выберите собственный локальный плейлист `.m3u` или `.m3u8`.
2. В меню **⚙** нажмите **«Обновить EPG»**. Плеер скачает полный архив [EPG.ONE](http://epg.one/epg2.xml.gz), подготовит облегчённую программу и загрузит её. Вручную скачивать и сокращать XML не требуется.
3. Откройте **«Каналы»**, выберите канал и запустите его двойным щелчком или кнопкой воспроизведения.

Плейлист, персональные ссылки, настройки и готовые файлы EPG не входят в установщик и репозиторий. Плейлист храните отдельно; плеер читает выбранный файл, не перезаписывая его.

## Каналы и избранное

- Группы читаются из `group-title` и `#EXTGRP`, при наличии обоих приоритет у `group-title`.
- Доступны выбор группы и поиск по названию или группе.
- Звёздочка рядом с каналом добавляет его в избранное или убирает оттуда.
- **«Только избранные»** показывает избранное из всех групп. Поиск остаётся доступен.
- Пути к файлам, последний запущенный канал, избранное и фильтры сохраняются между запусками. При открытии плеера последний канал запускается автоматически, даже если он скрыт фильтром.

## Программа передач

Поддерживаются локальные XMLTV `.xml` и `.gz`. Сопоставление выполняется по точному `tvg-id`, затем по уникальному названию. Время показывается в часовом поясе компьютера.

Кнопка **«Обновить EPG»** загружает основной EPG, израильский источник `https://iptv-epg.org/files/epg-il.xml`, дополнительный `https://iptv-epg.org/files/epg-zahaujlugl.xml.gz`, BCU Media `https://bcumedia.pro/epg.xml.gz`, IPTVX.one `https://iptvx.one/EPG` и TVTeam `http://epg.team/tvteam.xml.7.2`. При запуске каждый источник обновляется автоматически, если его сохранённый файл старше 12 часов или не загружается. Сначала показывается сохранённая программа; просмотр не ждёт скачивания. Обновление по расписанию при постоянно открытом плеере пока не выполняется.

Израильские каналы сопоставляются с названиями источника, включая 9, 11, 12, 13, HOT и Yes. Их расписание имеет приоритет только для сопоставленных израильских каналов; для остальных используется основной EPG. Дополнительный источник заполняет только пробелы: названия с префиксами стран сопоставляются со страной в группе или суффиксе канала. Неоднозначные HD/SD-совпадения пропускаются; часовые сдвиги сохраняются. BCU Media заполняет оставшиеся пробелы по точному `tvg-id` или уникальному названию, не заменяя работающие расписания предыдущих источников. IPTVX.one и TVTeam заполняют оставшиеся пробелы по уникальным названиям и меткам страны (`US -`, `IL:`, `[PL]`). Для израильских каналов русское расписание из этих источников имеет приоритет, если в ближайших передачах есть русский текст и нет иврита; при отсутствии или устаревании русского расписания сохраняется доступная программа из остальных источников. Каналы 9, 11, 12 и 13 сопоставляются явно. Русские варианты с пометкой `(ru)` используются только при наличии актуальных русских передач. Заглушки `No Data` и `Программа не найдена` не считаются программой и не показываются. Не все каналы плейлиста представлены в источнике.

Все шесть источников сохраняются отдельно за период три дня назад и три дня вперёд по UTC. Новый файл проверяется перед заменой; предыдущий сохраняется с окончанием `.previous.gz`. Если один источник недоступен, сохраняется его прежняя программа, остальные обновляются независимо.

## Видео и полный экран

**«Каналы»** и **«Программы»** сворачивают боковые панели. Кнопка расширения или **F11** включает видео на весь экран. Движение мыши показывает снизу название канала, текущую и следующую передачи, прогресс, управление, громкость и кнопку выхода. Панель скрывается через три секунды без действий и остаётся видимой при работе с ней. **Esc**, **F11** или **«Выйти»** возвращают прежний вид окна.

## Где хранятся данные

В установленной версии:

- `%LOCALAPPDATA%\CatLu IPTV\player-settings.json` — локальные настройки и избранное; без адресов потоков.
- `%LOCALAPPDATA%\CatLu IPTV\resurses\epg_small.xml.gz` — основная программа передач.
- `%LOCALAPPDATA%\CatLu IPTV\resurses\epg-israel.xml.gz` — израильская программа передач.
- `%LOCALAPPDATA%\CatLu IPTV\resurses\epg-regional.xml.gz` — дополнительная программа передач.
- `%LOCALAPPDATA%\CatLu IPTV\resurses\epg-bcu.xml.gz` — программа BCU Media.
- `%LOCALAPPDATA%\CatLu IPTV\resurses\epg-iptvx.xml.gz` — дополнительная программа IPTVX.one.
- `%LOCALAPPDATA%\CatLu IPTV\resurses\epg-tvteam.xml.gz` — дополнительная программа TVTeam.
- Плейлист остаётся по выбранному пользователем пути.

Удаление программы не удаляет эту папку данных. В рабочей копии проекта сохраняется прежняя структура: `player-settings.json` и `resurses` в корне проекта; привязки к диску D для установленной версии нет.

## Исходники и сборка

- `IptvPlayer/` — C# / .NET 8, WPF, LibVLCSharp, иконка кота.
- `installer/` — сценарий Inno Setup, сборка установщика и лицензии включённых компонентов.
- `test/` — проверки C# и анализаторы EPG на Python.
- `build_epg.py` — отдельный Python-сборщик EPG для ручной подготовки.

Для разработки нужны Windows x64 и .NET 8 SDK. Из корня репозитория:

```powershell
dotnet run --project .\IptvPlayer\IptvPlayer.csproj
```

Локальная сборка плеера:

```powershell
dotnet publish .\IptvPlayer\IptvPlayer.csproj -c Release -o .\IPTV
```

Запуск: `IPTV\CatLu IPTV.exe`. Для такой сборки нужна среда .NET 8 Desktop. В установщик она включается отдельной автономной сборкой.

Для сборки установщика установите Inno Setup 6 или 7 и выполните:

```powershell
.\installer\build.ps1
```

Версия берётся из `IptvPlayer.csproj`. Результат для текущей версии: `release\0.0.6\CatLu-IPTV-0.0.6-Setup-x64.exe` и `SHA256SUMS.txt`. Если компилятор установлен в другой папке, передайте его путь через `-InnoCompiler`.

## Проверки

```powershell
dotnet run --project .\test\Checks\Checks.csproj
dotnet run --project .\test\WindowChecks\WindowChecks.csproj
```

Проверяются M3U/XMLTV, часовые пояса, группы, несколько избранных каналов, совместимость настроек, пути установленной версии, безопасное обновление EPG, резервная копия, компоновка полного экрана и восстановление панелей. Эти команды не запускают сетевые потоки и не изменяют личные настройки.

Для отдельной подготовки EPG через Python требуются Python 3.14 и uv. Сохраните распакованный полный источник в `resurses\epg2.xml` и выполните `uv run python build_epg.py`. Кнопка обновления внутри плеера не требует Python.

## Ограничения 0.0.6

Архив передач, ручное сопоставление EPG и специальные параметры потоков провайдера (`#EXTVLCOPT`, дополнительные HTTP-заголовки, catch-up) пока не реализованы. Избранные каналы различаются названием и группой; полностью совпадающие название и группа имеют общую отметку.
