# CatLu IPTV 1.0.0

Исходники приложения: C# / .NET 8, WPF, LibVLCSharp. Иконка кота находится в `Assets`.

Установка, первый запуск, EPG, группы, избранное и полный экран описаны в [основном README](../README.md).

## Разработка

Запись текущего прямого эфира: кнопка «● Запись» в панели плеера → новый файл `.ts`.
Остановка — «■ Стоп запись»; при закрытии приложения файл также сохраняется.
Переключение каналов и пауза просмотра не меняют записываемый канал. Запись открывает
отдельное подключение к провайдеру и сохраняет поток без перекодирования. Запись по
расписанию и запись архива не предусмотрены. При обрыве сохраняется полученная часть;
после аварийного завершения она остаётся рядом с выбранным файлом под именем `*.part.ts`.

Из корня репозитория:

```powershell
dotnet run --project .\IptvPlayer\IptvPlayer.csproj
```

`AppPaths` определяет папку данных: в рабочей копии это корень проекта, в установленной версии — `%LOCALAPPDATA%\CatLu IPTV`. Существующие настройки и источники рабочей копии сохраняются.

## Установщик

Из корня репозитория выполните `.\installer\build.ps1`. Нужны .NET 8 SDK и Inno Setup 6/7. Версия берётся из `IptvPlayer.csproj`, установщик создаётся в `release\1.0.0`. .NET Desktop и LibVLC включаются в установщик; личные источники и настройки не включаются.
