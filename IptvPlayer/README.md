# CatLu IPTV

Windows x64, .NET 8, WPF и LibVLCSharp. Плейлист и EPG читаются только локально, исходные файлы не изменяются. Адреса не встроены в код, не сохраняются приложением и не выводятся в сообщения об ошибках. VLC работает с `--quiet`.

Готовая сборка находится в соседней папке `IPTV`: запустите `CatLu IPTV.exe`. Сохраняйте всю папку вместе с библиотеками. На этом компьютере необходимая среда .NET 8 Desktop уже установлена.

## Запуск

В PowerShell из этой папки:

```powershell
dotnet run --project .\IptvPlayer.csproj
```

1. Нажмите «Открыть M3U…» и выберите `D:\web\epg\resurses\playlist.m3u8`.
2. Выберите канал и нажмите «Воспроизвести» либо дважды щёлкните по нему.
3. Нажмите «Открыть EPG…» и выберите `D:\web\epg\resurses\epg_small.xml.gz` (можно также `epg2.xml`).

Поиск работает по названию и группе. Программа показывает текущую и следующие передачи, максимум 30, в часовом поясе Windows. XMLTV без смещения трактуется как UTC. Сопоставление: точный `tvg-id`, затем уникальное совпадение `tvg-name` или названия с XMLTV `display-name`, без учёта регистра. Неоднозначные названия не сопоставляются.

Парсер принимает HTTP(S), UDP, RTP и RTSP. Специальные директивы провайдера (`#EXTVLCOPT`, заголовки HTTP и catch-up) пока не применяются; каналы, которым они нужны, могут не открываться. Воспроизведение отправляет адрес выбранного канала его серверу.

## Проверка

```powershell
dotnet run --project ..\test\Checks\Checks.csproj
dotnet run --project ..\test\Checks\Checks.csproj -- D:\web\epg\resurses\playlist.m3u8 D:\web\epg\resurses\epg_small.xml.gz
```

Проверки выводят только результаты и количества, не ссылки. EPG читается последовательно, но передачи хранятся в памяти; для обычного просмотра предпочтителен облегчённый архив. Python для плеера не требуется: существующая подготовка EPG через `uv` остаётся отдельным этапом.

Плеер автоматически загружает последние выбранные плейлист и EPG и восстанавливает выбранный канал. При первом запуске используются файлы из resurses. Воспроизведение начинается по кнопке. Настройки хранятся в D:\web\epg\player-settings.json: пути, название и группа канала; адреса потоков не сохраняются. При недоступном или повреждённом файле отображается сообщение. Архив передач и ручное сопоставление пока не реализованы.

Проверено 20.10.2026: сборка Debug и публикация Release без ошибок и предупреждений; автоматические проверки парсеров прошли. На исходных локальных файлах: 4192 канала, 4155 совпадений с EPG, 37 без совпадения. Приложение запускается и штатно закрывается. Реальное изображение и звук каналов провайдера пока не проверены.

Документация библиотеки: https://github.com/videolan/libvlcsharp

## Новый интерфейс и обновление EPG

Видео расположено слева, программа выбранного канала — справа. Кнопка «Каналы» открывает поиск и список; после запуска канала список скрывается. Под видео отображаются название воспроизводимого канала, текущая и следующая передачи, ход текущей передачи, управление и громкость. F11 или кнопка полного экрана переключают полноэкранный режим, Esc выходит из него.

«Обновить EPG» загружает http://epg.one/epg2.xml.gz, сохраняет передачи за период от трёх дней назад до трёх дней вперёд по UTC и проверяет полученный архив. После успеха плеер переключается на resurses\epg_small.xml.gz. Предыдущая версия хранится в resurses\epg_small.xml.gz.previous.gz; при последующем успешном обновлении резервная копия заменяется. Полные локальные исходники epg2.xml и epg2.xml.gz не изменяются. Пустой, повреждённый или не содержащий актуальных передач результат не устанавливается. Временные файлы удаляются после завершения; при закрытии окна выполняется отмена операции. Таймаут обновления — пять минут.

Проверено: обновление из сети целиком, резервная копия, отбраковка некорректного XML/GZIP и устаревшего расписания, отмена, границы периода. Проверена компоновка тёмного интерфейса при ширине 1280 и 960. Источник: https://epg.one/.
## Группы и избранное

В панели «Каналы» выберите группу или «Все группы». Группы читаются из group-title и #EXTGRP; при наличии обоих используется group-title. Каналы без группы доступны как «Без группы». В текущем плейлисте 24 группы, все 4192 канала имеют группу.

Звёздочка рядом с каналом добавляет или убирает его из избранного. Флажок «Только избранные» показывает избранные каналы из всех групп, независимо от ранее выбранной группы. На время этого режима выбор группы недоступен; поиск продолжает работать. Отметки, выбранная группа и фильтр избранного сохраняются в player-settings.json; существующие пути и последний выбранный канал сохраняются. Для отметки используются название и группа, адреса потоков не записываются. Одинаковые название и группа считаются одним избранным каналом. Плейлист и EPG не изменяются.

Панель программы сворачивается кнопкой «Программа». В полном экране остаётся только видео; управление появляется снизу при движении мыши и скрывается через три секунды без действий. Выход: Esc, F11 или «Выйти» на всплывающей панели. После выхода восстанавливаются прежние панели.
