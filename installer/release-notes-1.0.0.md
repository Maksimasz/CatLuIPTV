## CatLu IPTV 1.0.0

Первая стабильная версия IPTV-плеера для Windows 10/11 x64.

- Несколько именованных плейлистов M3U/M3U8: загрузка по ссылке и из файла, группы, поиск и избранное.
- Программа передач из нескольких источников XMLTV с обновлением и резервными копиями, включая русские расписания израильских каналов при их наличии.
- Просмотр архива для совместимых плейлистов с `tvg-rec`: выбор дня и передачи, возврат в прямой эфир.
- Перемотка архива на 30 секунд назад и вперёд; доступна и в полном экране.
- Ручная запись текущего прямого эфира в TS без перекодирования. Отображаются канал, длительность и размер. Переключение просматриваемого канала не останавливает запись; при обычном закрытии плеера файл сохраняется.
- Полный экран с автоматически скрываемой панелью управления.
- Проверка обновлений при запуске, каждые 24 часа и вручную. Установщик обновляет программу поверх предыдущей версии с сохранением настроек, плейлистов, избранного и EPG.

### Установка и обновление

Скачайте `CatLu-IPTV-1.0.0-Setup-x64.exe` и запустите поверх установленной версии. Удалять старую программу не нужно. .NET 8 и LibVLC включены в установщик. Файл `SHA256SUMS.txt` содержит контрольную сумму SHA-256.

### Ограничения

- Каналы и доступ к IPTV не входят в приложение: добавьте свой плейлист.
- Наличие и глубина архива определяются провайдером; для выбора передачи требуется расписание EPG за нужный день.
- Запись запускается и останавливается вручную, требует включённого компьютера и открытого плеера, использует отдельное подключение к провайдеру. Записи по расписанию пока нет.
- Установщик не подписан цифровым сертификатом: Windows может показать предупреждение SmartScreen.
- Автоматические обновления без авторизации GitHub станут доступны после открытия репозитория.
