## CatLu IPTV 0.0.7

- Управление именованными плейлистами: добавление из файла или по ссылке, редактирование названия и источника, удаление из плеера.
- Выпадающий список плейлистов в столбце каналов. Каждый плейлист имеет отдельный список каналов; избранное общее.
- Тёмное меню настроек и окна ввода без белых рамок. Список каналов остаётся открытым при переключении.
- Обновления плеера: ручная проверка, проверка при запуске и каждые 24 часа, ссылка на новую версию рядом с «Каналы».
- Установщик обновляет программу в прежней папке, сохраняет пользовательские данные. Перед установкой из плеера сохраняется резервная копия настроек; скачанный установщик проверяется по SHA-256.

### Установка

Скачайте `CatLu-IPTV-0.0.7-Setup-x64.exe` и запустите поверх прежней версии. Удалять плеер перед обновлением не нужно. Плейлисты, избранное, настройки и EPG сохраняются. Windows 10/11 x64; .NET и LibVLC включены.

### Ограничение приватного репозитория

Для скачивания этого релиза требуется вход в GitHub с доступом к репозиторию. Автоматическая проверка обновлений в плеере пока требует публичного источника релизов. GitHub-токен в приложение не встроен.
